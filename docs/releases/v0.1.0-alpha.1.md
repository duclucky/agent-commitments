# v0.1.0-alpha.1 — experimental builder toolkit

Agent Commitments adds shared USDC budget authority, signed reservations and recoverable reconciliation to agent workflows on Arc. Contracts/SDK are reusable independently of the document example, console, API or hosted services.

## Install

```sh
npm install https://github.com/duclucky/agent-commitments/releases/download/v0.1.0-alpha.1/agent-commitments-sdk-0.1.0-alpha.1.tgz
```

The release includes the standalone SDK archive and SHA256SUMS. The archive embeds compiled network configuration, depends on pinned viem, includes TypeScript declarations and has no workspace dependency or install scripts. There is no npm registry publication.

See [starter](../../examples/sdk-starter/README.md), [integration](../integration.md), [SDK reference](../sdk-api.md) and [mainnet read-only quickstart](../quickstart-arc-mainnet.md).

## Validation

Local build/typecheck/lint, 14 domain tests, 39 SDK tests, 52 contract tests (four fuzz properties at 256 runs each), 6 failure-injection tests, 13 console/server tests and 3 pilot-scope tests passed. Local integration/E2E and deployment rehearsal passed. Standalone installation/ESM/declarations were checked in an isolated npm project.

The [read-only mainnet verification](../deployments/community-alpha-mainnet-verification-2026-10-12.json) checks deployed source/compiler/runtime, binding, 19 canonical pilot receipts, roles, payouts/refunds, final ledger, backing and allowances. It sends no new transaction. CI results are separate from local evidence and must be checked on GitHub; this document does not predeclare remote CI success.

## Boundaries

- Experimental alpha, independent review pending. Studio was tool-assisted self-review, not an independent audit or Circle certification.
- Internal mainnet pilot only; zero independent customers claimed. Budget currently empty.
- Provider quotes require ECDSA EOAs. ERC-1271 is unsupported.
- Two pinned ERC-8183 adapters; mainnet supports a documented Draft subset, not full/future conformance.
- Circle Developer-Controlled Wallets executor is testnet-only; mainnet pilot used Agent Wallet CLI.
- No live CCTP/Gateway route, AP2/x402 certification or hosted production service.
- Evaluator trust, issuer transfer restrictions, direct-vault-transfer lockup and orphan Open jobs remain documented limitations.

Operator journals, raw signed transactions, keystores, credentials, audit workspaces and raw local logs are excluded from source publication. Public evidence contains selected chain IDs, addresses, job IDs and receipt metadata.
